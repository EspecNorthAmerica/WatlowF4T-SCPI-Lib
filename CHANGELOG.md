# Changelog 

Version 0.2.

## Compatibility Update

This release adds updated compatibility notes for current Python 3 versions. The library has been tested with newer Python 3 environments to help users confirm that the software can still be used on currently supported Python installations.

Tested With

* Python 3.9
* Python 3.13

## Changed

Updated documentation to include Python compatibility information.
Added notes for users installing the library from a cloned repository.
Clarified that the library communicates with the Watlow F4T controller using SCPI over TCP/IP port 5025.

## Not Changed

* No changes were made to the SCPI command structure.
* No changes were made to the main controller class interface.
* No changes were made to the TCP/IP communication method.
